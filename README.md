# VoxeBlockS 0.2 — rebuild from zero

Android voxel sandbox written in Java + OpenGL ES 2.0.

Features in this rebuild:
- camera yaw/pitch with correct left/right basis
- camera-relative joystick movement
- procedural voxel terrain
- face-culling mesh
- block breaking and placement
- real hotbar/inventory counts
- persistent world edits and player position
- sprint, crouch, double-jump and dash
- first/third-person camera
- touch HUD

Target: Android 6.0+ / landscape, optimized for mid-range phones.
